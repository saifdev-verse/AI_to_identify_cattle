🐄 Agri Breed AI

AI-Powered Cattle & Buffalo Breed Identification

Identify the Breed. Empower the Farmer.

📌 About:

Agri Breed AI is a deep learning-based web application that identifies cattle and buffalo breeds from images and provides breed-related information.

✨ Features:

- Image-based breed prediction
- ResNet-based deep learning model
- User-friendly web interface
- FastAPI backend
- Breed information through database integration

🛠️ Tech Stack:

- AI/ML: Python, PyTorch, ResNet
- Backend: FastAPI
- Frontend: HTML, CSS, JavaScript
- Database: MySQL

⚙️ How It Works:

1. Upload a cattle or buffalo image.
2. The AI model predicts the breed.
3. View the prediction and available breed information.
